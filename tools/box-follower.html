Click an empty box to assign its log file. Boxes start red — nothing is assumed to be following until the log says so, or you click the box to acknowledge it green. After that, a box turns red the moment its log contains "You are no longer auto-following", and turns green again automatically when the log contains "You will now auto-follow". If your follow command doesn't log that second phrase, you can also click a red box to acknowledge it back to green manually. Hover a box for the file icon to reassign or clear it. Use Pop out to float a compact, always-on-top copy of the grid over EverQuest — drag its edge to resize, and it keeps reading your log files live as long as this tab stays open. Check Alert sound to get a chime whenever a box drops follow — use the built-in default or upload your own clip with Upload sound, and preview it any time with Test sound. Use Save profile to remember your current file assignments, layout, and sound choice under a name, and Load profile to restore them later — the browser may ask you to re-confirm file access once per session, which is a security requirement and not something this tool can skip.
